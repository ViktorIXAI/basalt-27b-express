### 1. How Attention State is Stored

The project stores attention state (Key-Value cache, or KV) in two primary formats, selectable via configuration:

*   **FP16 (Default):** The documentation for the Qwen3.8-27B model states that `--kv fp16` is the default. In this mode, the KV cache is stored in 16-bit floating-point precision.
*   **Int8:** The documentation explicitly mentions `--kv int8` as an alternative. For the Qwen3.8-27B model, the text notes that "Int8 KV prompt attention reads 8-bit P V." This implies the keys and values are quantized to 8-bit integers to save memory.

Additionally, the configuration examples show that `kv` can be set to `"int8"` or `"q4_0"` (in the low-VRAM example), though the detailed performance metrics in the changelog specifically compare `fp16` and `int8`.
