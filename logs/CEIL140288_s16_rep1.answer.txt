### 1. How Attention State is Stored

The project uses different storage formats and memory hierarchies depending on the model architecture.

**Qwen3.8-Flash-Next (Mixture-of-Experts)**
*   **Formats:** The KV cache can be stored as `fp16` (default), `int8`, `q4_0`, or `k8v4`.
    *   `int8` halves the VRAM usage compared to `fp16`.
    *   `k8v4` keeps Keys as int8 and Values as 4-bit (816 bytes per cell vs. 1,056 for `int8`).
*   **Memory Hierarchy:**
    *   **VRAM:** The primary storage location.
